# Water Intake Tracker

A simple, elegant web application to help users track their daily water consumption. Built with vanilla HTML, CSS, and JavaScript, this app features a modern UI with smooth animations and interactive elements.

## Features

- Track water intake in milliliters
- Visual progress bar showing percentage of daily goal
- Daily goal tracking (set to 5000ml)
- Celebration animation upon reaching daily goal
- Responsive design that works on all devices
- Clean, modern interface with gradient accents
- Quick input via keyboard (Enter key) or button
- Reset functionality to start fresh

## Usage

1. Enter the amount of water consumed in milliliters in the input field
2. Click "Add Water" or press Enter to log the amount
3. Watch the progress bar and percentage update in real-time
4. Receive a celebration notification when reaching the daily goal
5. Use the "Reset" button to start over

## Installation

No installation required! This is a standalone HTML file that runs in any modern web browser.

1. Download the `index.html` file
2. Open it in your preferred web browser
3. Start tracking your water intake

## Technical Details

The application uses:
- Custom CSS variables for consistent theming
- CSS Grid and Flexbox for responsive layouts
- CSS transitions and animations for smooth interactions
- Local JavaScript state management
- Event listeners for keyboard and click interactions
